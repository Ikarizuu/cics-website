01 — Undergraduate Programs

Undergraduate programs.

BSIT

BS Information Technology

PAASCU Level II · CHED Center of Development in Information Technology

Program Description

Rigorous training in the latest concepts and applications of information technology, with a practical approach to the IT industry.

Graduates can apply computing concepts across IT domains, analyze problems and define computing requirements, design and evaluate solutions, and manage the security, reliability, and efficiency of systems.

Includes Capstone Project 1 & 2 and a practicum of at least 486 hours (4th year, 2nd semester).

Curriculum Overview

  • Introduction to Computing
  • Fundamentals of Programming
  • Fundamentals of Database Systems
  • Data Structures and Algorithms
  • Human Computer Interaction
  • Networking 1 & 2
  • Information Assurance and Security 1 & 2
  • Internet of Things
  • Integrative Programming Technologies 1
  • CISCO Networking Semesters 1–3

Career Paths

  • Web Developer
  • Full-Stack Developer
  • UI/UX Designer
  • Mobile App Developer
  • Network Engineer
  • Systems Administrator
  • Cybersecurity Analyst
  • Cloud Engineer
  • Database Administrator
  • Data Analyst
  • IT Project Manager
  • IT Instructor

BSCS

BS Computer Science

Specializations in Game Development and Intelligent Systems

Program Description

Prepares students in computing theory and its applications, abstract reasoning, analytical thinking, and research.

Graduates can apply computing and mathematics across domains of computer science and design algorithms for complex computing problems.

Includes Thesis 1 & 2 and a practicum of at least 240 hours (special term).

Curriculum Overview

  • Object-Oriented Programming
  • Discrete Structures 1 & 2
  • Programming Languages
  • Introduction to Machine Learning
  • Natural Language Processing
  • Computer Vision / Image Processing
  • Introduction to Game Programming
  • Game Design Principles and Practice
  • 3D Graphics and Animation
  • Thesis 1 & 2

Career Paths

  • Software Engineer
  • Application Developer
  • Mobile App Developer
  • Data Scientist
  • AI Engineer
  • ML Engineer
  • NLP Specialist
  • Game Programmer
  • Game Designer
  • Security Analyst
  • DevOps Engineer
  • Researcher

02 — Specializations & Tracks

Specializations.

BSIT

Specialization in Web Development

Adds Internet Languages and Tools 2, Web Systems and Technologies, and Graphic Design.

Specialization in Network Technology

Same first- to third-year courses, with a focus on CISCO and networking courses.

BSCS

Specialization in Game Development

Real-world game design and development. Careers include Game Designer, Level Designer, Game Programmer, and Gameplay Engineer.

Specialization in Intelligent Systems

Problem-solving with Artificial Intelligence. Careers include AI Programmer, Machine Learning Engineer, and Computer Vision and Image Data Analyst.
